# 体裁路由：先判类型，再走流水线

流水线默认是 **A 类：行业/观点专栏**。但 **B 类：个人叙事**（亲身经历、纪念、随笔、真实故事）的走法完全不同——阶段 1 不调研、阶段 3 不用信息图、字数下限不适用、去味的重点也不是拆套话。

**阶段 0 预检之后第一件事就是判体裁。**判错会在后面每个阶段制造返工。

## 快速判型

| 信号 | 判为 |
|---|---|
| 「分析 XX」「怎么看 XX」「招股书 / 趋势 / 方法论 / 财报」 | A 类 |
| 「我经历了 XX」「昨天 / 我家 / 亲眼」「纪念」「随笔」「真实故事」 | **B 类** |
| 一句话里同时有「我」和数据/报告 | 问一句，别默认 |

## 两种体裁对照

| 维度 | A. 行业/观点（默认） | B. 个人叙事 |
|---|---|---|
| 阶段 1 调研 | 必须：搜竞品、核实数据、A/B/C 分级 | **跳过**：事实全部来自用户叙述，只写一份轻量简报定调子与骨架 |
| 事实来源 | 外部，必须有出处 | 用户本人，逐字采信 |
| 字数 | 2500–5000 汉字 | **无下限**，1200–2000 即可，注水反而毁掉 |
| 结构 | 现象 → 机制 → 启示，小标题较多 | 时间线 / 场景推进，小标题少，纯段落叙事 |
| 阶段 3 配图 | 信息图 / 流程图（HTML 渲染） | **真照片优先**；无照片才用极简插画，**禁用信息图** |
| 阶段 3.5 封面 | 设计版（深底 + 巨大单字视觉锤） | **照片封面优先**，设计版备选 |
| 结尾 | 落在动作或未决边界 | **不升华、不总结意义**，落在一个具体动作或一个画面 |
| 附带的公共呼吁 | 不适用 | 放在故事之后，短、具体、可执行，不写成说教 |
| 门禁重点 | 数据出处、标题方向 | 调子、结构骨架、**写作纪律**（下节） |

## B 类铁律：不虚构细节

第五篇（流浪猫）踩出来的。个人叙事里，为了让文笔「好看」而补的细节，全都是假的，而且用户一眼能认出来——这直接伤信任。

**不许补：**
- 具体数字：两公斤猫粮、半分钟、僵持两分钟、走出去十几米
- 具体动作：转了两圈看底盘、洗食盆、把猫粮拎回家、买了猫包
- 具体环境：下雨、便利店、在货架前站了一会儿
- 视觉细节：眼睛睁得挺圆、灯光很暗（除非用户说过）

**允许写：**
- 用户原话里的事实，一个不增不减
- 用户当时的心里的想法（合理推演，但要克制，且别写成名言体）
- 把已知细节铺开写、控制节奏、留白——这是写法，不是补事件
- 节奏性的概括（「一天两次」「流程也固定」），只要概括的是真发生过的事

**写完必须做一次虚构细节自查**：逐段对照用户原始叙述，凡是原话里没有的具体名词 / 数量 / 动作，删掉。自查结果在阶段 5 对账时一并复核。

## B 类的门禁差异

- **阶段 1**：给用户看「调子 + 结构骨架 + 写作纪律」，不搜外部、不给数据分级
- **阶段 2**：给全文 + 标题备选，同时**主动声明哪几句是 AI 加的**（如「一米，是她能给我的距离」），让用户决定保留还是删掉。别混在正文里蒙过去
- **阶段 3**：用户提供照片时走 `references/photo-handling.md`；有敏感照片先给判断再让用户定
- **阶段 5**：字数下限不适用；重点不是拆套话，而是**复查虚构细节**（用初稿/终稿逐句比对）
- **阶段 6**：不变

## A 类也要注意

A 类的「不虚构」是**数据层面**（数字/引语/案例必须有出处，C 级不用）；B 类的「不虚构」是**事件层面**（连一个动作、一个数量都不能加）。两者不是同一条规则，别混用。

完整执行见 `references/fact-check.md`（A 类）与 `references/photo-handling.md`（B 类配图）。
