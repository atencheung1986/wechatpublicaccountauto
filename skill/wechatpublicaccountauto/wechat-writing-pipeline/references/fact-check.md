# 事实核查规范

公众号文章的可信度全在数据上。写稿前先把数字分级，定级决定能不能用。

## 三级分类

| 级别 | 定义 | 用法 |
|---|---|---|
| **A** | 有官方原件可追：报告 PDF、机构官网、上市公司披露、政府统计 | 可直接用，正文标注「据《报告名》」 |
| **B** | 权威媒体或平台转述，能追到发布方，但拿不到原始报告 | 可用，但必须写明转述来源，不假装是一手数据 |
| **C** | 只有自媒体互相转述，搜不到原始出处 | **一律不用**。不写进正文，也不写进备选 |

判级办法：拿数字去搜，看能不能找到发布机构 + 报告名 + 年份。三样缺两样，就是 C。

## 典型 C 级数据（已核实，别再用）

- 「78% 的企业设 35 岁门槛」——广泛流传，找不到原始调研出处
- 「大厂 35 岁以上员工占比 7.3%」——同上，只有转述

判定 C 级时，在 brief 里记一条「已排除」并写明原因，避免下次重复劳动。

## 写作时的硬约束

1. 每个数字在正文里必须能看出出处，格式统一为「据 ××（年份）统计/报告」。
2. 不同机构的数字不要混着做算术（口径不同，推导不成立）。
3. 不确定就降级表述：写「据某平台统计」不如写「某平台 2026 年的一份统计显示」。
4. 示例、模板、虚构的简历条目必须显式标注「格式示范，非真实项目」。
5. 不编人物故事、不编引语、不编对话。humanizer-zh 的边界也禁止这些。

## 改写后的数字对账

去 AI 味之后必须跑一遍，确认事实零膨胀、零丢失：

```python
import re
def load(p):
    t = open(p, encoding='utf-8').read()
    return re.sub(r'^---.*?---\n', '', t, flags=re.S)

a, b = load('02-draft.md'), load('03-humanized.md')
pat = re.compile(r'\d+(?:\.\d+)?%|\d+(?:\.\d+)?万|\d+(?:\.\d+)?岁|\b\d{4}\b')
na, nb = set(pat.findall(a)), set(pat.findall(b))
print('新增:', sorted(nb - na))   # 必须为空
print('丢失:', sorted(na - nb))   # 为空，或需逐项确认是刻意删除
for kw in ['智联', '脉脉', 'PMI', 'CSDN', '猎聘']:
    print(kw, a.count(kw), b.count(kw))
```

新增非空 = 改写越界，必须回退。丢失项要逐条确认是刻意删除还是误删。
